# Computer Vision using OpenCV

This repository contains a collection of mini computer vision applications developed using **Python** and **OpenCV** as part of my college project.

The project demonstrates basic image processing and motion detection techniques using real-world examples.

---

## Projects Included

### 1. Wildlife Motion Detection
**Objective:**
Detect moving animals in a video using frame differencing and contour detection.

**Dataset**
- tiger.mp4

**Concepts Covered**
- Video Capture
- Frame Differencing
- Grayscale Conversion
- Gaussian Blur
- Thresholding
- Dilation
- Contour Detection
- Bounding Rectangles

---

### 2. Industrial Defect Detection

**Objective:**
Identify defects from industrial images using OpenCV image processing techniques.

**Dataset**
- defect.jpg

**Concepts Covered**
- Image Processing
- Edge Detection
- Thresholding
- Contour Analysis

---

### 3. Face Detection

**Objective**
Detect human faces in images using OpenCV.

**Concepts Covered**
- Haar Cascade Classifier
- Face Detection
- Image Processing
